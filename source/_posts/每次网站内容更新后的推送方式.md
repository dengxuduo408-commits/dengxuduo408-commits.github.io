# 有两种方式：
## 一、git三步骤：
### ① git add .  ② git commit -m "备注"  ③ git push origin main

## 二、hexo自带三步骤：
### ① hexo clean —— 清除缓存与原public
### ② hexo g     —— 将source里的.md文件及其他文件编译成静态网页文件（html），生成到public文件夹里，网站访问的就是此页面
### ③ hexo d     —— 将public里生成好的网页发布到Github Pages仓库

# 实际工作只用选择 ***方式一*** 
## 按理，方式一只有把代码推送到GitHub仓库的功能，没有更新网页。但是现在有**Actions**工具，会自动把我们推送的代码弄到云端。
